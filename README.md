# skhub-skworld-io

The static landing page for [skhub.skworld.io](https://skhub.skworld.io), served via GitHub Pages
directly from this repository's `index.html` and `CNAME`.

skhub is SKWorld's self-hosted collaboration hub: files, chat, video calls, and office docs, built
on a hardened Nextcloud deployment (the `optional/skhub` role in the
[SKStacks](https://github.com/smilinTux/skstacks) sovereign infrastructure framework). See the
[skhub README](https://github.com/smilinTux/skstacks/blob/main/v1/ansible/optional/skhub/README.md)
in that repo for the full technical reference this site is grounded in.

This site is part of the [SKWorld](https://skworld.io) sovereign AI ecosystem.
